### 这一页在讲什么

第 14 页的命题 3 只管有限个选项。可是经济学里最常见的选项是**商品组合**：买 $x_1$ 斤苹果、$x_2$ 斤香蕉，$x_1$、$x_2$ 可以是任何非负实数，选项有无穷多个。这时：

1. 不是每个理性偏好都能用效用函数表示。反例是**字典序偏好**。
2. 如果偏好还满足一个叫**连续性**的条件，就一定能用效用表示，而且效用函数是连续的（命题 4）。

### 先补基础

:::prereq[商品组合是一个向量]
有两种商品时，一个选项写成 $x=(x_1,x_2)$：第一种买 $x_1$ 份，第二种买 $x_2$ 份。所有这样的点组成平面 $\R^2$；有 $n$ 种商品时，组合是 $x=(x_1,\dots,x_n)$，属于 $\R^n$。$X\subseteq\R^n$ 说的是：选项是 $n$ 种商品的组合。
:::

:::prereq[序列与极限：$x_n\to x$]
序列是按顺序排好的一列数（或点）：$x_1,x_2,x_3,\dots$。$x_n\to x$ 读作“$x_n$ 趋向于 $x$”，意思是 $n$ 越来越大时，$x_n$ 和 $x$ 要多近有多近。

例：$x_n=\dfrac1n$，即 $1,\ \dfrac12,\ \dfrac13,\dots$，它趋向于 0。点也一样：$\left(\dfrac1n,0\right)$ 趋向于 $(0,0)$。详见 :go[序列与极限]{to="basics/sequences-continuity#sequence"}。
:::

:::prereq[可数与不可数]
如果一个无限集合的元素能排成一队、一个一个编号（第 1 个、第 2 个、……），就说它是**可数**的。正整数、有理数（分数）都是可数的。全体实数**不可数**：无论怎么编号，总有实数被漏掉。这是数学里一个著名的结论，这里直接使用。详见 :go[可数集]{to="basics/sequences-continuity#countable"}。
:::

### 逐句读懂

:::orig
Not all $\succeq$ are representable by $u$.
:::

- **意思**：不是所有偏好 $\succeq$ 都能用效用函数 $u$ 表示（即使它完备、传递）。

:::orig
Example: **Lexicographic preferences**: prioritize $x_1$ before $x_2$.
:::

- **意思**：例子：:term[字典序偏好]{k=lexicographic-preference}，优先看 $x_1$，再看 $x_2$。准确的定义见下一节。

:::orig
No real-valued utility function exists.
:::

- **意思**：字典序偏好不存在任何实值效用函数来表示它。

:::orig
**Definition 6 (Continuity).** $\succeq$ continuous if $(x_n,y_n)\to(x,y)$ and $x_n\succeq y_n\ \forall n\Rightarrow x\succeq y$.
:::

- **读法**：定义 6（连续性）：如果只要 $(x_n,y_n)$ 趋向于 $(x,y)$，并且对所有 $n$ 都有 $x_n\succeq y_n$，就一定有 $x\succeq y$，那么称 $\succeq$ 是连续的。
- **意思**：:term[连续性]{k=continuity-preference}说的是：“不差于”这个关系在取极限时**不会突然反转**。每一对 $x_n$ 都不比 $y_n$ 差，那么它们的极限 $x$ 也不比 $y$ 差。

:::orig
**Proposition 4.** If $X\subseteq\R^n$ and $\succeq$ is complete, transitive, continuous, then $\succeq$ has a continuous utility representation.
:::

- **意思**：命题 4：选项是 $n$ 种商品的组合，偏好完备、传递、连续，那么一定存在一个**连续**的效用函数表示它。“连续”的效用函数是指：组合变化一点点，分数也只变化一点点，不会突然跳。证明思路在第 16 页。

### 字典序偏好：像查字典一样比较

查字典时先比第一个字母，第一个字母相同再比第二个。字典序偏好比较两个组合也是这样：

- 若 $x_1>y_1$，则 $x\succ y$（第一种商品多的更好，不管第二种）；
- 若 $x_1=y_1$ 且 $x_2>y_2$，则 $x\succ y$（第一种一样多，再比第二种）；
- 只有 $x_1=y_1$ 且 $x_2=y_2$ 时，$x\sim y$。

:::example[比几对组合]
- $(3,0)$ 和 $(2,100)$：第一个分量 $3>2$，所以 $(3,0)\succ(2,100)$。第二种商品多 100 份也弥补不了第一种少的那 1 份。
- $(2,5)$ 和 $(2,3)$：第一个分量相同，比第二个，$5>3$，所以 $(2,5)\succ(2,3)$。
- $(2.001,0)$ 和 $(2,1000)$：$2.001>2$，前者更好。

生活中的例子是奥运奖牌榜：先比金牌数，金牌一样再比银牌。40 金 27 银的国家排在 39 金 90 银的国家前面。
:::

字典序偏好是完备的（任意两个组合都能这样比出结果），也是传递的，所以它是**理性**偏好。它的奇怪之处是：两个不同的组合永远不会一样好，也就是说它没有“无差异曲线”，每个组合只和它自己无差异。

::fig{src="figures/lecture1/p15-lexi.svg" caption="字典序偏好下，和 x = (2, 1.5) 相比：右边整块（第一种商品更多）和正上方的一段都比 x 好；左边整块和正下方的一段都比 x 差。和 x 一样好的只有 x 自己。" alt="坐标图：竖线 x1 = 2 把平面分成左右两块，右边浅蓝色表示比 x 好，左边浅红色表示比 x 差；竖线上 x 点上方一段为蓝色、下方一段为红色" width="80"}

对比一下普通的偏好：比如“两种商品加起来越多越好”时，和 $x$ 一样好的组合连成一条斜线（无差异曲线），比 $x$ 好的在线的右上方。字典序偏好下，这条线缩成了一个点，“好”和“差”的分界是一条竖线，而且在这条竖线上还要再按第二种商品分上下。下面要讲的连续性，正是被这条竖线“劈开”的：从右边无限靠近竖线下半段的点都比 $x$ 好，一走到竖线上就突然变差。

### 为什么字典序偏好找不到效用函数

课程阅读材料在脚注里给出了论证，这里用大白话讲一遍。假设某个 $u$ 表示字典序偏好，看看会出什么问题。

:::proof[字典序偏好不能用实值效用函数表示]
1. 对每个实数 $\alpha\ge0$，看两个组合 $(\alpha,0)$ 和 $(\alpha,1)$。第一个分量相同，第二个分量 $1>0$，所以 $(\alpha,1)\succ(\alpha,0)$，于是 $u(\alpha,1)>u(\alpha,0)$。 :why[字典序的定义 + $u$ 表示偏好]
2. 所以每个 $\alpha$ 都在数轴上占了一段“专属区间” $I_\alpha=\big(u(\alpha,0),\,u(\alpha,1)\big)$，长度大于 0。 :why[第 1 步]
3. 取两个不同的数 $\alpha<\beta$。因为 $\beta>\alpha$，$(\beta,0)\succ(\alpha,1)$，所以 $u(\beta,0)>u(\alpha,1)$：区间 $I_\beta$ 整个在 $I_\alpha$ 的右边，两段**不重叠**。 :why[字典序的定义]
4. 任何一段长度大于 0 的区间里都有有理数。从每段 $I_\alpha$ 里挑一个有理数，不同的 $\alpha$ 挑到的有理数一定不同（区间不重叠）。 :why[有理数的性质]
5. 这样就给**每个**非负实数 $\alpha$ 配上了一个**不同的**有理数。可是有理数可数、实数不可数，有理数不够分。矛盾。 :why[可数与不可数]
6. 所以这样的 $u$ 不存在。 :why[反证法]
:::

直观地说：实数轴上“放得下”的互不重叠的区间只有可数多段，而字典序偏好需要给每个实数 $\alpha$ 都留一段，数轴装不下。

### 字典序偏好违反连续性

:::example[一列越来越好、极限却变差的组合]
取 $x_n=\left(\dfrac1n,0\right)$，$y=(0,1)$。

- 对每个 $n$：$x_n$ 的第一个分量 $\dfrac1n>0$，所以 $x_n\succ y$，当然 $x_n\succeq y$。
- 当 $n$ 越来越大，$x_n$ 趋向于 $x=(0,0)$。
- 比较极限 $x=(0,0)$ 和 $y=(0,1)$：第一个分量相同，第二个 $0<1$，所以 $y\succ x$，**$x\succeq y$ 不成立**。

每一项都“不差于” $y$，极限却比 $y$ 差，违反定义 6。这就是字典序偏好的“断裂”之处。
:::

### 例子

:::example[连续的偏好长什么样]
偏好由 $u(x)=x_1+x_2$ 给出（两种商品可以一比一替代）。若 $x_n\succeq y_n$，即 $x_{n,1}+x_{n,2}\ge y_{n,1}+y_{n,2}$，两边取极限，不等号保持，得到 $x_1+x_2\ge y_1+y_2$，即 $x\succeq y$。所以这个偏好是连续的。一般地，由连续的效用函数给出的偏好都是连续的。
:::

### 常见困惑

:::pitfall[连续性为什么被认为是“无害”的假设？]
阅读材料指出：任何**有限**个观察到的选择，只要满足 HARP，就也和连续性相容。只有无穷多个观察才可能否定连续性，而现实数据总是有限的。所以连续性基本不会和数据冲突，主要作用是让数学上好处理。
:::

:::pitfall[字典序偏好是理性的，但不能用效用表示]
“理性”（完备、传递）和“能用效用表示”是两回事。选项有限时两者等价（命题 3）；选项无限时，还需要连续性这样的额外条件（命题 4）。
:::

### 这一页的要点

:::summary
- 字典序偏好：先比第一个分量，相同再比第二个。它理性，但没有任何实值效用函数能表示它。
- 连续性：若 $(x_n,y_n)\to(x,y)$ 且 $x_n\succeq y_n$ 对所有 $n$ 成立，则 $x\succeq y$。字典序偏好违反它。
- 命题 4：$X\subseteq\R^n$ 上完备、传递、连续的偏好，一定有连续的效用表示。
:::

### 自测

::::quiz[字典序比较]
按字典序偏好比较：$(1,7)$ 和 $(1.5,0)$；$(4,2)$ 和 $(4,2.5)$。
:::answer
- $(1.5,0)\succ(1,7)$：第一个分量 $1.5>1$，第二个分量不用看。
- $(4,2.5)\succ(4,2)$：第一个分量相同，第二个 $2.5>2$。
:::
::::

::::quiz[换一个序列也能说明不连续吗？]
取 $x_n=\left(1+\dfrac1n,0\right)$，$y=(1,5)$。字典序偏好下，这个序列能说明违反连续性吗？
:::answer
**能。** 每一项 $x_n$ 的第一个分量 $1+\dfrac1n>1$，所以 $x_n\succ y$。极限 $x=(1,0)$，与 $y=(1,5)$ 第一个分量相同，第二个 $0<5$，所以 $y\succ x$，$x\succeq y$ 不成立。和正文的例子一样，违反定义 6。
:::
::::
