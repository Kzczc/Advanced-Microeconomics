### 这一页在讲什么

经济学想描述“一个人怎么做选择”。第一步，是找一种**精确的语言**来描述“他觉得哪个更好”。这一页就在造这种语言：

1. 把所有可选的东西放进一个集合 $X$；
2. 用一个符号 $\succeq$ 表示“至少一样好”，再由它派生出“更好” $\succ$ 和“一样好” $\sim$；
3. 提出两条要求——**完备性**和**传递性**。同时满足这两条的偏好，经济学称为 :term[理性偏好]{k=rational-preference}（rational preference）。

后面整门课（效用函数、消费者需求、不确定性下的选择）都建立在这两条要求之上，所以这一页是地基。

### 先补基础

:::prereq[集合与“属于”符号 $\in$]
- **集合**就是“一堆东西放在一起”，用大括号列出来。例如 $X=\{\text{苹果},\ \text{香蕉},\ \text{橙子}\}$。
- $x\in X$ 读作“$x$ 属于 $X$”，意思是 $x$ 是 $X$ 里的一个元素。例如“苹果 $\in X$”。
- 课件里的 $X$ 叫作 :term[选择集]{k=choice-set}（choice set）：所有“可能被选中”的选项。它可以很具体（三种水果），也可以很抽象（例如所有“苹果数量、香蕉数量”的组合）。

更多内容见 :go[数学基础：集合]{to="basics/sets-logic#set"}。
:::

:::prereq[“当且仅当” $\iff$ 与“对所有”]
- $A \iff B$ 读作“$A$ 当且仅当 $B$”，意思是 $A$ 和 $B$ **说的是同一件事**：$A$ 成立时 $B$ 一定成立，$B$ 成立时 $A$ 也一定成立。
- “For all $x, y\in X$”（数学里常写 $\forall\, x,y\in X$）读作“对 $X$ 中任意两个元素 $x,y$”，意思是**不管挑哪两个**都要成立，没有例外。

更多内容见 :go[数学基础：逻辑符号]{to="basics/sets-logic#quantifiers"}。
:::

### 逐句读懂

:::orig
Let $X$ = set of possible choices.
:::

- **意思**：用 $X$ 表示所有可能的选项。后面出现的 $x, y, z$ 都是 $X$ 里的选项。

:::orig
Weak preference: $x \succeq y \iff$ “$x$ at least as good as $y$”.
:::

- **读法**：$x \succeq y$ 读作“$x$ 弱偏好于 $y$”，口语就是“$x$ 至少和 $y$ 一样好”。
- **意思**：这个人拿 $x$ 和 $y$ 比，觉得 $x$ **不比 $y$ 差**——可能更好，也可能一样好。
- **为什么叫“弱”**：它把“更好”和“一样好”两种情况都包括了，要求比较宽松，所以叫 :term[弱偏好]{k=weak-preference}。

:::orig
Strict preference: $x \succ y$ if $x \succeq y$ but not $y \succeq x$.
:::

- **读法**：$x \succ y$ 读作“$x$ 严格偏好于 $y$”，即“$x$ 比 $y$ 好”。
- **意思**：两个条件同时成立：① $x$ 至少和 $y$ 一样好；② **反过来不成立**，$y$ 并不至少和 $x$ 一样好。合起来就是“$x$ 真的更好”。这叫 :term[严格偏好]{k=strict-preference}。

:::orig
Indifference: $x \sim y$ if $x \succeq y$ and $y \succeq x$.
:::

- **读法**：$x \sim y$ 读作“$x$ 与 $y$ 无差异”。
- **意思**：$x$ 至少和 $y$ 一样好，**同时** $y$ 也至少和 $x$ 一样好——那只能是“一样好”。这叫 :term[无差异]{k=indifference}。

:::intuition[三个符号的关系：一张表看懂]
拿任意两个选项 $x$、$y$，问两个问题：“$x \succeq y$ 吗？”“$y \succeq x$ 吗？”一共四种回答：

| $x\succeq y$ ? | $y\succeq x$ ? | 结论 |
|:---:|:---:|:---|
| 是 | 否 | $x \succ y$（$x$ 更好） |
| 否 | 是 | $y \succ x$（$y$ 更好） |
| 是 | 是 | $x \sim y$（一样好） |
| 否 | 否 | 这个人**说不出**哪个好——完备性就是要排除这一行 |

所以只要知道了 $\succeq$，$\succ$ 和 $\sim$ 就都确定了：$\succeq$ 是“原材料”，另外两个是由它“加工”出来的。
:::

:::orig
**Definition 1 (Completeness)** For all $x, y \in X$, either $x \succeq y$ or $y \succeq x$, or both.
:::

:::def[定义 1：完备性（Completeness）]
对 $X$ 中任意两个选项 $x,y$，$x \succeq y$ 与 $y \succeq x$ 至少有一个成立。
:::

- **意思**：任意挑两个选项，这个人**总能比较**：要么觉得 $x$ 不比 $y$ 差，要么觉得 $y$ 不比 $x$ 差，要么两个都成立（一样好）。上表最后一行“说不出”的情况不允许出现。这就是 :term[完备性]{k=completeness}。
- **一个容易忽略的细节**：$x$ 和 $y$ 可以是同一个选项。取 $y=x$，完备性给出 $x\succeq x$，即“任何东西至少和它自己一样好”（数学上叫**自反性**，reflexivity）。第 7 页的证明会用到这一点。

:::orig
**Definition 2 (Transitivity)** If $x \succeq y$ and $y \succeq z$, then $x \succeq z$.
:::

:::def[定义 2：传递性（Transitivity）]
对 $X$ 中任意三个选项 $x,y,z$：如果 $x \succeq y$ 且 $y \succeq z$，那么 $x \succeq z$。
:::

- **意思**：偏好可以“接力”：$x$ 不比 $y$ 差、$y$ 又不比 $z$ 差，那么 $x$ 也不比 $z$ 差。这就是 :term[传递性]{k=transitivity}。
- **生活里的说法**：“苹果至少和香蕉一样好，香蕉至少和橙子一样好”，那么“苹果至少和橙子一样好”。
- **它排除了什么**：排除“兜圈子”。如果某人觉得苹果比香蕉好、香蕉比橙子好、橙子又比苹果好，那么无论他手里拿着哪一个，总有另一个他觉得更好——这样根本选不出“最好的”。

### 例子

:::example[三种水果：一个理性的偏好]
设 $X=\{a,b,c\}$，其中 $a$ = 苹果，$b$ = 香蕉，$c$ = 橙子。小明觉得苹果最好，香蕉和橙子一样好：

$$
a \succ b,\qquad a \succ c,\qquad b \sim c .
$$

逐条检查：

1. **完备性**：三对 $(a,b)$、$(a,c)$、$(b,c)$ 都有结论，每个选项和自己比也都是“一样好”，所以任意两个都能比较，满足。
2. **传递性**：把所有“接力”都试一遍。例如 $a\succeq b$ 且 $b\succeq c$，传递性要求 $a\succeq c$——确实成立（$a\succ c$）；又如 $c\succeq b$ 且 $b\succeq c$，要求 $c\succeq c$——也成立。所有情况都成立，满足。

所以小明的偏好是理性的，可以把它排成一行：$a \succ b \sim c$。
:::

::widget{name="pref-checker" caption="动手试试：自己设定三种水果之间的偏好，看看是否满足完备性和传递性"}

:::example[反例：石头剪刀布式的“偏好循环”]
小红觉得：$a \succ b$，$b\succ c$，$c \succ a$。

检查传递性：由 $a\succeq b$ 和 $b\succeq c$，传递性要求 $a \succeq c$；但她认为 $c\succ a$，按严格偏好的定义，这意味着“$a\succeq c$ 不成立”。**矛盾**，所以她的偏好不满足传递性，不是理性偏好。下一页的“框架效应”就是现实中出现这种循环的例子。
:::

### 常见困惑

:::pitfall[“$\succeq$”不是“$\ge$”]
$\succeq$ 长得像“大于等于”，但它比较的是**选项**（苹果、香蕉），不是数字。“$x\succeq y$”只表示“这个人觉得 $x$ 不比 $y$ 差”，和 $x$、$y$ 本身有没有数值无关。等到 :slide[第 14 页]{n=14} 有了**效用函数** $u$，才会把它翻译成数字比较 $u(x)\ge u(y)$。
:::

:::pitfall[“一样好”也是一种明确的态度]
完备性不要求“一定分出高下”。$x\sim y$（一样好）完全符合完备性。完备性排除的是“**无法比较**”，不是“**一样好**”。
:::

:::pitfall[传递性只写了 $\succeq$，但 $\succ$ 和 $\sim$ 也会跟着传递]
由 $\succeq$ 的传递性可以推出：$x\succ y$ 且 $y\succ z$ 时 $x \succ z$；$x\sim y$ 且 $y\sim z$ 时 $x\sim z$。以 $\succ$ 为例：由传递性先得到 $x\succeq z$；如果还有 $z\succeq x$，再和 $x\succeq y$ 接力就得到 $z\succeq y$，与 $y\succ z$（即“$z\succeq y$ 不成立”）矛盾，所以 $z\succeq x$ 不成立，$x\succ z$。这些“副产品”在后面的证明里会反复用到。
:::

### 这一页的要点

:::summary
- $\succeq$（至少一样好）是基本符号；$\succ$（更好）和 $\sim$（一样好）都由它定义出来。
- **完备性**：任意两个选项都能比较。**传递性**：偏好不会“兜圈子”。
- 同时满足完备性和传递性的偏好称为**理性偏好**，它是整门课的起点。
:::

### 自测

::::quiz[判断违反了哪条定义（一）]
设 $X=\{a,b,c\}$，某人认为 $a\succeq b$、$b\succeq c$，但**不认为** $a\succeq c$。他的偏好违反了哪条定义？
:::answer
违反**传递性**。传递性要求由 $a\succeq b$ 和 $b\succeq c$ 推出 $a\succeq c$，而他不认为 $a\succeq c$。

补充：如果他的偏好是完备的，那么“$a\succeq c$ 不成立”就意味着 $c\succeq a$ 成立，也就是 $c\succ a$——他的偏好形成了 $a\succeq b\succeq c\succ a$ 的循环。
:::
::::

::::quiz[判断违反了哪条定义（二）]
如果某人对两个选项 $x,y$ 既不认为 $x \succeq y$，也不认为 $y\succeq x$，这违反了哪条定义？
:::answer
违反**完备性**：完备性要求 $x\succeq y$ 与 $y\succeq x$ 至少有一个成立。这正是前面那张表的最后一行“说不出”。
:::
::::
