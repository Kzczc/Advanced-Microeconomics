这是一份写给**数学基础几乎为零、英语不太好、没学过经济学**的同学的课件精讲。课件每一页都配一段中文讲解：先说这一页想解决什么问题，再把课件上的英文和公式一句一句读懂，然后用例子、图和交互小实验把道理讲透。

### 怎么用这个网站

1. **按讲、按部分读。** 左边目录是“讲 → 部分 → 每一页”。每个部分是一个网页，里面按顺序排着这一部分的所有课件页。
2. **左图右文。** 宽屏上，左边是课件原页（点一下可以放大看），右边是讲解；往下读讲解时，左边的课件会一直停在屏幕上。手机上是上图下文。
3. **看不懂符号就查。** 正文里带**虚线下划线**的词，鼠标停上去（手机上点一下）会弹出解释；也可以去 :go[符号速查]{to="symbols"} 和 :go[术语表]{to="glossary"}。
4. **数学没底就先补课。** 每一页用到的基础知识都放在“先补基础”框里，并链接到 :go[数学基础]{to="basics/sets-logic"} 的对应小节。完全没接触过集合、函数、极限的同学，建议先花一小时读完数学基础的四页。
5. **动手做一做。** 很多页有交互图：拖动点、调滑块，看结论怎么变。旁边的说明会用中文告诉你“现在为什么是这样”。
6. **每页最后有自测。** 先自己想，再点“看答案与解析”。

### 讲解里的彩色方框

| 方框 | 用来做什么 |
|---|---|
| 课件原文 | 课件英文原文的准确转录（公式重新排版过，比课件截图更清楚） |
| 定义 / 命题 | 正式的定义和结论，保留课件原来的编号 |
| 先补基础 | 这一页用到、之前没讲过的数学或经济学概念 |
| 直观理解 | 用大白话、类比、图来解释“为什么” |
| 例子 | 真的算一遍的具体例子，楷体排版 |
| 证明拆解 | 证明的每一步做了什么、依据是什么（小标签标出依据） |
| 易错点 | 最容易误解、最容易混淆的地方 |
| 核对 | 课件和讲义说法不一致、或课件有笔误的地方 |
| 要点 / 自测 | 每页结尾的回顾和练习 |

### 快捷键

- <kbd>/</kbd> 或 <kbd>Ctrl</kbd> + <kbd>K</kbd>：全站搜索（中英文都可以，例如“传递性”“HARP”“拟凹”）。
- <kbd>←</kbd> <kbd>→</kbd>：在一个部分里跳到上一页 / 下一页课件。
- 顶栏右边的 A− / A+：调整字号（会记住你的选择）。
