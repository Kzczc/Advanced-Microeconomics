# 高级微观经济学 · 逐页精讲

港科大（广州）Siguang Li 老师《高级微观经济学》课件的中文逐页讲解，写给数学零基础、英语较弱、没学过经济学的读者。
每一页课件都配一段讲解：先说这一页要解决什么问题，再逐句读懂英文原文和公式，然后用生活中的例子、插图和可以动手拖动的交互图把它讲透。

在线阅读：<https://kzczc.github.io/Advanced-Microeconomics/>

## 内容进度

- **第 1 讲 选择理论：偏好、选择与效用**：29 页全部完成，分 6 个部分。另有“自测汇总（错题本）”和“定义与命题速查”两个复习页。
- **补课与速查**：集合与逻辑、函数与二元关系、序列与连续、凸集与拟凹函数四篇数学补课，外加符号速查和术语表。
- **第 2 讲 消费者理论**：课件已整理，讲解写作中。
- **第 3 讲 不确定性下的决策**：计划中。

目前共有 60 张插图、14 种交互图、84 道带答案的自测题、116 个可以悬停查看的术语。

## 怎么用这个网站

- **左图右文**：左边是课件原页（点击可放大），右边是讲解。宽屏时课件会跟着你往下走；“专注阅读”可以收起课件，只看讲解。
- **每页的结构**：一句话总结、本页小节标签、“先补基础”、“逐句读懂”、例子、常见困惑、自测题。看完一页可以点“我看懂了”，首页会显示进度。
- **术语和符号**：带虚线的词悬停或点击就能看解释；不认识的符号查“符号速查”。
- **搜索**：按 `/` 打开搜索。从搜索结果点进去，命中的词会在页面上高亮。
- **翻页**：键盘 ← → 跳到上一页 / 下一页课件；Esc 关闭弹窗。
- **复习**：“自测汇总”把一讲的全部自测题放在一起，可以标记“会了 / 还不会”、只看错题、打乱顺序；“定义与命题速查”把定义、命题和每页一句话排在一页上，适合考前扫一遍。
- **阅读设置**：夜间模式、放大缩小字号，设置会被记住。
- **打印**：任何页面都可以打印或存为 PDF，打印版会去掉导航，并把折叠的答案展开。
- **学习记录**：首页可以把“看懂了”的进度、错题标记和阅读设置导出成一个文件，换浏览器或换电脑时再导入。

## 本地预览

需要 Node.js 22（与自动发布用的版本一致）和 Python 3。

```bash
npm ci
npm run build          # 生成 dist/
npm run serve          # 打开 http://127.0.0.1:8766/
```

## 写内容与检查

```bash
npm run check                                     # 检查全部内容：公式、指令、链接、术语、禁用写法
npm run figures                                   # 重新生成全部插图（需要 XeLaTeX 和 matplotlib）
python3 tools/figures/lecture1/p19-convexity.py   # 只重新生成某一张插图
```

`tools/qa/` 里是浏览器自动检查脚本（需要 `playwright-core` 和 Chrome）：

- `qa.mjs`：逐页截图，检查横向溢出和脚本报错（桌面、手机两种宽度）；
- `linkcheck.mjs`：检查 `dist/` 里的全部站内链接和锚点；
- `features.mjs`：端到端测试错题本、速查页、搜索高亮、夜间模式、学习记录导出等阅读功能；
- `wtest.mjs`：配合 `tools/widget_preview.html` 给交互图截图；
- `audit.py`（只需要 Python）：从零基础读者的角度审查内容，列出符号速查没收录的符号、过长的段落、没配图的页、没解释的英文缩写。

写作规范见 `authoring/WRITING.md`，技术规范见 `authoring/SPEC.md`。

## 仓库结构

- `slides/`、`readings/`：原始课件与配套阅读材料（PDF）
- `content/`：全部讲解内容（Markdown）
  - `course.yaml`：课程结构（讲 → 部分 → 每部分包含哪些页）
  - `lecture1/pNN.md`：第 1 讲每一页课件的讲解；`lecture1/sheet.md`：定义与命题速查
  - `basics/*.md`：数学补课
  - `glossary/*.yaml`：术语表；`symbols.md`：符号速查
- `public/`：课件页图（`slides/`）与插图（`figures/`），原样复制到网站
- `site/`：构建脚本 `build.mjs`、样式、页面脚本与交互图（`assets/js/widgets/`）
- `tools/`：内容检查 `check_content.mjs`、插图脚本 `figures/`、浏览器检查 `qa/`
- `authoring/`：写作规范与技术规范

## 发布

推送到 `main` 后，GitHub Actions 依次运行内容检查、构建，然后发布到 GitHub Pages。公式在构建时由 KaTeX 排好，浏览器端不做公式计算。
